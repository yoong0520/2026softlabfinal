# AI 코스웨어 실증 수업 결과보고서 작성 도우미

고등교육 에듀테크 소프트랩 실증 교과목 담당 교수가 1~15주차 AI 코스웨어 활용 내용을 핵심 항목만 입력하면,
생성형 AI가 결과보고서(Ⅰ~Ⅵ)를 작성하고 PDF·DOCX 파일로 저장할 수 있는 단일 페이지 웹앱입니다.

## 사용 방법
1. 사이트를 열고 기본 정보 → 수업 운영 핵심 → 주차별 활용 → 결과 수치(선택) → 소감 메모를 입력합니다.
2. "AI로 보고서 생성"을 누르면 보고서 초안이 작성됩니다. 미리보기에서 직접 수정하거나 항목별 "다시 쓰기"를 할 수 있습니다.
3. "PDF 저장" 또는 "DOCX 저장"으로 파일을 내려받습니다.

입력 내용은 사용자의 브라우저에만 자동 저장되며 서버로 전송되지 않습니다.

## AI 기능 설정
- claude.ai 아티팩트로 열면 별도 설정 없이 AI가 동작합니다.
- GitHub Pages 등 일반 주소로 열면 상단 "AI 설정"에서 다음 중 하나를 입력해야 합니다.
  - 사업단이 제공하는 AI 중계 서버 주소(권장: 교수는 키 없이 사용)
  - 개인 Anthropic API 키(브라우저에만 저장)

## 파일 구성
- `index.html` — 앱 전체(HTML·CSS·JS 단일 파일). 외부 라이브러리는 docx.js, html2pdf.js를 CDN에서 불러옵니다.

## 성과 포럼 참가확인증 발급(`cert/`)
2026년 고등교육 에듀테크 소프트랩 성과 포럼(2026. 11. 24.) 참가확인증 발급 페이지입니다. 결과보고서 도우미와는 별개로 동작합니다.

- 주소: https://yoong0520.github.io/2026softlabfinal/cert/
- 동작: 성명·소속·이메일 입력 → 입력 순서대로 발급번호(에듀테크소프트랩사업단 2026-001호부터) → A4 확인증 → PDF 내려받기(브라우저 안에서 생성)
- 발급대장: 구글 시트 「2026 소프트랩 성과 포럼 참가확인증 발급대장」에 발급번호·성명·소속·이메일·발급일시가 자동 기록됨
- 번호 부여: Apps Script 「소프트랩 성과 포럼 참가확인증 발급번호」 웹 앱(코드는 `relay/cert-receiver.gs`). 같은 이메일은 처음 번호 재사용
- 문안·날짜 수정: `cert/index.html` 에서 「2026년 고등교육 에듀테크 소프트랩 성과 포럼」, 「2026. 11. 24.(화)」, 「2026년 11월 24일」, 「에듀테크소프트랩사업단장」을 검색해 고친 뒤 main 에 push. 발급번호 앞의 기관 표기는 `ISSUER_TAG` 한 곳만 고치면 됨
- Apps Script 코드를 고친 뒤에는 「배포 관리 → 새 버전」으로 배포해야 반영됨(주소 유지)
