# AI 코스웨어 실증 수업 결과보고서 작성 도우미

고등교육 에듀테크 소프트랩 실증 교과목 담당 교수가 1~15주차 AI 코스웨어 활용 내용을 핵심 항목만 입력하면,
생성형 AI가 결과보고서(Ⅰ~Ⅵ)를 작성하고 PDF·DOCX 파일로 저장할 수 있는 단일 페이지 웹앱입니다.

## 사용 방법
1. 사이트를 열고 기본 정보 → 수업 운영 핵심 → 주차별 활용 → 결과 수치(선택) → 소감 메모를 입력합니다.
2. "AI로 보고서 생성"을 누르면 보고서 초안이 작성됩니다. 미리보기에서 직접 수정하거나 항목별 "다시 쓰기"를 할 수 있습니다.
3. "PDF 저장" 또는 "DOCX 저장"으로 파일을 내려받습니다.

입력 내용은 사용자의 브라우저에만 자동 저장되며 서버로 전송되지 않습니다.

## AI 기능 설정
- claude.ai 아티팩트로 열면 별도 설정 없이 AI가 동작합니다.
- GitHub Pages 등 일반 주소로 열면 상단 "AI 설정"에서 다음 중 하나를 입력해야 합니다.
  - 사업단이 제공하는 AI 중계 서버 주소(권장: 교수는 키 없이 사용)
  - 개인 Anthropic API 키(브라우저에만 저장)

## 파일 구성
- `index.html` — 실증 수업 결과보고서 작성 도우미(HTML·CSS·JS 단일 파일)
- `consulting/index.html` — 수업운영 컨설팅(교수자 자가진단 → 컨설턴트 검토) 페이지
- `relay/worker.js` — Cloudflare Workers AI 중계 서버
- `relay/drive-upload.gs` — 구글 드라이브 제출 수신기(Apps Script). 결과보고서 트랙별 저장과 컨설팅 요청·결과 저장을 모두 처리
- 외부 라이브러리는 docx.js, html2pdf.js를 CDN에서 불러옵니다.
