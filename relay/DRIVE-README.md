# 트랙별 구글 드라이브 자동 저장 설치 안내 (Google Apps Script, 무료)

교수가 사이트에서 「사업단에 제출」을 누르면 PDF·DOCX가 유은님 구글 드라이브의 실증 Track별 폴더에 자동 저장되고,
「실증 결과보고서 제출 현황」 시트에 한 줄씩 기록됩니다. 교수는 구글 로그인이 필요 없습니다.

## 이미 만들어진 것(유은님 드라이브)
- 제출함: 2026 소프트랩 실증 수업 결과보고서 제출함
  - Track 1 신규 개발 / Track 2 신규 심화 / Track 2 기개발 심화 / 기타 에듀테크 / 미분류(Track 미선택)
  - 실증 결과보고서 제출 현황(시트)

## 설치 순서 (약 5분, 유은님 구글 계정으로)
1. https://script.google.com 접속 → 「새 프로젝트」
2. 편집기의 기존 코드를 모두 지우고 `drive-upload.gs` 내용을 붙여넣기 → 저장(Ctrl+S)
   - 프로젝트 이름은 아무거나(예: 소프트랩 제출 수신기)
3. 오른쪽 위 「배포」 → 「새 배포」
   - 유형 선택(톱니바퀴) → 「웹 앱」
   - 설명: 아무거나
   - 다음 사용자 인증 정보로 실행: 「나(yueun88@gmail.com)」
   - 액세스 권한이 있는 사용자: 「모든 사용자」  ← 꼭 이 값이어야 교수가 제출 가능
   - 「배포」
4. 권한 승인 창이 뜨면: 계정 선택 → 「고급」 → 「(프로젝트명)(으)로 이동」 → 「허용」
   (구글이 "확인되지 않은 앱"이라고 경고하지만 유은님 본인 스크립트이므로 문제없음)
5. 배포 완료 창의 「웹 앱 URL」(https://script.google.com/macros/s/.../exec)을 복사해 전달
   → 사이트 index.html의 `UPLOAD_URL = ""` 안에 넣어 배포하면 「사업단에 제출」 버튼이 나타남

## 동작 확인
- 브라우저에서 웹 앱 URL을 열면 {"ok":true,"message":"...동작 중입니다"} 가 보이면 정상
- 사이트에서 제출하면 Track 폴더에 파일이 생기고 현황 시트에 줄이 추가됨

## 참고
- 같은 파일명이 이미 있으면 제출 시각을 붙여 저장(이전 제출본 보존)
- 코드를 고친 뒤에는 「배포」→「배포 관리」→ 연필 아이콘 → 버전 「새 버전」→「배포」를 해야 반영됨(URL은 그대로)
- 폴더 ID를 바꾸려면 drive-upload.gs 상단의 ID만 수정

## 수업운영 컨설팅 페이지 연동 (2026-11-05 추가)
- 컨설팅 페이지: https://yoong0520.github.io/2026softlabfinal/consulting/
- 드라이브 폴더: 「2026 소프트랩 수업운영 컨설팅」 안에 1_컨설팅 요청(교수자 자가진단) / 2_컨설팅 결과(컨설턴트 검토) / 9_데이터(자동 저장, 수정 금지) / 수업운영 컨설팅 현황(시트)
- 흐름: 교수자가 자가진단 제출 → 접수 코드 6자리 발급 → 컨설턴트가 코드로 불러와 검토·AI 초안 → 결과 제출 → 교수자는 같은 코드로 결과 확인
- 수신기 코드(drive-upload.gs)가 갱신되었으므로 「배포」→「배포 관리」→ 연필 → 버전 「새 버전」→「배포」로 재배포해야 동작함(URL은 그대로)
- 9_데이터 폴더의 req_코드.json / res_코드.json 은 사이트가 읽고 쓰는 원본이므로 손으로 고치거나 지우지 말 것
